Controles (Quest 3 Touch Plus & PC)

Meta Quest 3

  • Menu Start / Pause: Clique na borda do estádio (- Diminuir / + Aumentar) ou no painel acima.
  • Modo Posicionamento: Aponte o controle direito na mesa/chão e aperte Gatilho Direito para fixar.
  • Mover Estádio / Escala: Segure Grip (lateral) para arrastar; use o Analógico Direito (cima/baixo = escala, esq/dir = girar).
  • Analógico Esquerdo: Move o jogador (direção fixa no estádio, sem girar com a cabeça).
  • Botão A: Roubar a bola (defesa) / Tocar com assistência (ataque).
  • Botão B: Chute no gol (segure p/ carregar força).
  • Gatilho Direito: Correr (sprint).
  • Gatilho Esquerdo: Trocar de jogador controlado.
  • Botão X: Carrinho defensivo.
  • Start / Menu Esquerdo (ou Y): Abrir/Fechar Menu de Pause.

PC Desktop (Teste rápido)

  • WASD / Setas: Mover jogador (direção fixa no estádio).
  • E ou J: Roubar a bola / Tocar com assistência.
  • Espaço: Chute no gol (segure p/ força).
  • C ou F: Carrinho defensivo.
  • Shift: Correr (sprint).
  • Q: Trocar de jogador.
  • Mouse (arrastar / scroll): Girar e dar zoom em volta do estádio (ou clique na borda no Start/Pause).
  • Enter / P / R: Iniciar / Pausar-Continuar / Reiniciar partida.
